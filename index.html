Workaddict

Free and open-source time tracking

A simple time tracker for you and your team. No subscription, no ads, no tracking.

  • Free. No paid plans, no limits.
  • Open source. Read the code on GitHub
  • Your entries stay in your own private GitHub repository.

Everything a small team needs

  • Free, no server

    A static website on GitHub Pages. No subscription, no seats to count.

  • Your data, your repository

    Entries are stored in a private GitHub repository you control. Every change is a commit you can revert.

  • Made for teams

    Worker, editor and team leader roles, plus a live “Team now” view of who is tracking right now.

  • A timer that follows you

    Start on your laptop, stop on your phone. Overnight entries just work.

  • Reports and exports

    Charts by project, tag and member. Export to PDF, Excel, OpenDocument or CSV.

  • Switch from Clockify

    Bring your projects, tags and entries over with the built-in import.

    Read the import guide

How it works

  1. Create a private repository

    An empty private repository on GitHub holds your team’s data.

  2. Create a token

    A fine-grained token that can access only that repository.

  3. Sign in

    Enter the repository and the token. The app sets everything up on first use.
